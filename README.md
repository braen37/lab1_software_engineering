## Опис проєкту

Проєкт створено в межах виконання лабораторної роботи №3 для опанування
інструментів GitHub та ведення технічної документації.

DentalControl призначений для обліку пацієнтів, запису на прийоми, фіксації
наданих стоматологічних послуг і оплат та формування підсумкових звітів.

Основні ролі користувачів:

* **Реєстратор:** ведення карток пацієнтів, запис на прийом та облік оплат.
* **Лікар:** перегляд розкладу та внесення відомостей про проведені прийоми.
* **Власник:** керування обліковими записами, прайсом і перегляд звітів.

У цьому репозиторії оформлюється навчальна документація; реалізацію
програмної системи не заявлено.

## Використані технології

* Git — система контролю версій.
* GitHub — вебінтерфейс репозиторію, гілки та Pull Request.
* Markdown — форматування документації.

## Структура репозиторію

* `README.md` — опис проєкту.
* `student_info.txt` — інформація про виконавця; додається в гілці
  `feature/student-info`, після чого зміни зливаються в `main`.
